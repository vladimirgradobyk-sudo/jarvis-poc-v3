About This Report

This report is built from the latest run logs across all six JARVIS skills — 1,000 completed runs spanning PRD generation, user stories, HLD/LLD architecture documents, story implementation, and PR reviews. Token consumption, API call counts, and cost breakdowns were extracted from actual run telemetry and computed against current published model pricing (Nov 2026). The statistics below reflect real production workload distribution across four agent roles, three captain models, and three writer model tiers (Opus 4.6, Opus 5.5, Sonnet 5.5). All figures are gross costs before prompt caching — the caching section quantifies the reduction available.

Methodology

  • 1 writer per run — single-writer council mode (review phase requires ≥2 writers)
  • Captain adjudicates on all skills except Review PR (solo path, no captain required)
  • Captain model distribution: Opus 5 (45%) · GPT Astra-6 (30%) · GPT-5.4 (25%)
  • Opus 4.6 handles core delivery tasks (PRD, Implement Story, Review PR); Opus 5.5 handles architecture (HLD, LLD); Sonnet 5.5 handles structured output (User Stories)
  • Token volumes are per-call measured averages including system prompt, context window, and output
  • GPT-5.4 and GPT Astra-6 priced at published market rates (Nov 2026)
  • Baseline excludes prompt caching — with caching enabled, costs reduce by 30–60%
